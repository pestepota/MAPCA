 <--> **Welcome to MAPCA - the Generative Cartographic System** <-->

  MAPCA - the Generative Cartographic System, is a school project with the purpose of creating a map for as many uses as you want! Use it as a map creator for you RPG world, for your strategy games or simply for an personal lore, you name it!<br>
<br>
  #About the Project <br>
    MAPCA is a web-tool developed to create a random map using JavaScript in according to your wishes and liking!<br>
<br>
  #What are it's Features <br>
    **Map Generation:** Create random and unique maps for RPGs, world building or strategy games.<br>
    **Save & Load:** Save and Load your maps from a diverse range of formats.<br>
    **Custom Settings:** Customize and tweak your maps to be the exact way you want them to be.<br>
<br>
  #Tech Stack<br>
    **HTML 5 & CSS3** (Custom retro/terminal styled UI)<br>
    **JavaScript** (Map generation logic)<br>
<br>
