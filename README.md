 <--> **Welcome to MAPCA - the Generative Cartographic System** <-->

  MAPCA - the Generative Cartographic System, is a school project with the purpose of creating a map for as many uses as you want! Use it as a map creator for you RPG world, for your strategy games or simply for an personal lore, you name it!

  #About the Project
    MAPCA is a web-tool developed to create a random map using JavaScript in according to your wishes and liking!

  #What are it's Features
    **Map Generation:** Create random and unique maps for RPGs, world building or strategy games.
    **Save & Load:** Save and Load your maps from a diverse range of formats.
    **Custom Settings:** Customize and tweak your maps to be the exact way you want them to be.

  #Tech Stack
    **HTML 5 & CSS3** (Custom retro/terminal styled UI)
    **JavaScript** (Map generation logic)
